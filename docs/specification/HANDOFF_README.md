# ASTER — Space Health Research Console

**Status: English product specification and implementation handoff. The application, presentation, and narrated videos have not been built in this folder yet.**

ASTER is a proposed simulation-first, offline-capable astronaut health research application. It brings together breathing exposure, sensor integrity, and exercise response in an evidence-linked local workflow.

The team selected all three modules and a simulation-first delivery strategy. This bundle gives the implementation agent the scientific boundaries, product design, architecture, data contracts, scenarios, build sequence, quality gates, and media production requirements.

## Intended final delivery

Repository: [umitcancinar/NasaSpaceApps](https://github.com/umitcancinar/NasaSpaceApps).

The future release should include working application source, reproducible scenarios, baseline comparisons, verified offline behavior, sensor/gateway interfaces with honest verification labels, an English README, an editable presentation with PDF export, and narrated English product videos recorded from the real app.

The application defaults to English and supports Turkish, German, French, Spanish, Arabic, and Japanese core interfaces. Documentation, presentation, narration, and release material remain English.

## Scientific position

This is a research concept, not a clinically validated or flight-qualified system. Existing smart garments, gas monitors, mechanical biosensors, and medical data platforms are explicitly acknowledged. Novelty and superiority of the proposed methods remain hypotheses to evaluate, not established facts.

Research checked: 13 November 2026. Dependency versions, skill installers, and competition requirements should be rechecked when implementation begins.

This handoff does not install dependencies, connect real sensors, transmit health data, create GitHub commits, or publish media. The build specification instructs the next agent to implement and verify those deliverables where applicable.
